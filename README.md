# Witch Cult Reader

A Chrome/Edge extension for [Witch Cult Translations](https://witchculttranslation.com/) (Re:Zero web novel) that colors each character's dialogue, separates dialogue / narration / inner thoughts, themes the page, remembers your reading position and chapter, and reads chapters aloud as a play — with a voice per character, optionally generated by a local AI server (GPT-SoVITS / Style-Bert-VITS2) on your own desktop.

## Layout

- `docs/voice-setup-guide.md` — full download + setup guide for the local AI character voices (GPT-SoVITS install, Re:Zero voice packs, wiring).
- `work/build.py` — single source of truth. Generates the extension files into `outputs/witch-cult-reader/`.
- `work/check.cjs` — jsdom test suite against real saved chapter/index pages.
- `work/chapter.html`, `work/index.html` — saved page fixtures the tests run against.
- `work/package.json` — dev dependency (jsdom) for the tests.
- `outputs/witch-cult-reader/` — the built, loadable extension (commit this so the repo is always loadable).
- `outputs/witch-cult-reader.zip` — packaged copy, rebuilt by `zip -r` (ignored by git).

## Build & test

Run both from the repo root (paths are relative to it):

```
python3 work/build.py     # regenerate outputs/witch-cult-reader/
node work/check.cjs       # run the full jsdom suite (needs: cd work && npm install)
```

## Load it in Chrome

1. Open `chrome://extensions`, enable **Developer mode**.
2. **Load unpacked** → select `outputs/witch-cult-reader/`.
3. Open a Witch Cult Translations chapter; click **✦ Reader** bottom-right.

For the local AI character voices, see "Local AI character voices" in the extension README (`outputs/witch-cult-reader/README.md`) — it walks through installing GPT-SoVITS on the desktop and wiring per-character voice clips.
